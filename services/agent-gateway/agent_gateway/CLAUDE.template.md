# Working rules (gateway default for repos without a CLAUDE.md)

- Make the smallest change that fully does the task.  Match the surrounding code's style,
  naming and comment density.
- Build and run the repo's tests before committing; say plainly if they fail or don't exist.
- Commit with a short, plain message saying what changed and why.  No attribution trailers.
- Never commit secrets, credentials or personal data.
- Don't delete files you didn't create in this task; say which ones should go instead.
- If the task is ambiguous, ask one question rather than guess.
